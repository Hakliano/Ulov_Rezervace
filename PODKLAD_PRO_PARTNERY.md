# Podklad pro partnerské smlouvy a dokumentaci

**Produkt / značka:** ULOV KLIENTY · platforma Ulov Rezervaci  
**Verze:** 1.0  
**Datum:** srpen 2026  
**Účel:** Kompletní popis **obchodní nabídky**, **poskytovaných služeb** a **funkcí FLOW** (majitel i pracovník), aby právní oddělení mohlo připravit smlouvy, VOP, ceníky a přílohy pro partnery.

**Související:**  
- GDPR / zpracování údajů → `For Compliance v1.md`

## 3. Co je zahrnuto v měsíční platbě „Partner pro vaši provozovnu“

Za měsíční poplatek (499 / 799 Kč) se partnerovi poskytuje zejména:

### 3.1 WEB na míru

- Grafický návrh webu (a rezervační stránky) podle brandu  
- Veřejný web: úvod, galerie, personál, ceník, novinky, kontakt  
- Vlastní správa obsahu majitelem (⚙): texty, fotky, ceník, novinky, logo, favicon, banner pro tým  
- Webová adresa zdarma po dobu spolupráce  
- Další úpravy webu **v ceně** (na rozdíl od jednorázového webu)  
- Jednotný vzhled webu a rezervací  
- Nastavení a předání přístupů  

### 3.2 Online rezervace

- Rezervační stránka pro zákazníky (nová rezervace, moje rezervace)  
- Výběr služeb, personálu, volných termínů  
- Potvrzení rezervace e-mailem (odkaz), storno tokenem  
- Připomínky a další transakční e-maily (SMTP partnera)  
- Zákaznický účet (volitelně), .ics do kalendáře  
- QR platby / žádost o platbu nebo zálohu (e-mail s QR, SPAYD)  
- NO-show evidence a blokace e-mailů **v rámci provozovny**  
- GDPR nástroje majitele (export / výmaz na žádost) — viz `For Compliance v1.md`  

### 3.3 FLOW pro provozovnu a tým

Kompletní popis → **kapitola 6**. Stručně v měsíční ceně:

- Přístup majitele a pracovníků do FLOW  
- Kalendář a denní provoz rezervací  
- Pracovní doba, dovolené / absence  
- Správa pracovníků a FLOW přístupů (majitel)  
- Interní banner / oznámení  
- Firemní e-mail ve FLOW (IMAP — pokud partner zapne a nastaví schránku)  
- Rezervační pravidla, e-mailové šablony, statistiky, audit, NO-show (majitel)  

### 3.4 Osobní a technická podpora

- Technická konzultace a průběžná podpora  
- Podpora zakladatele (WhatsApp, e-mail, dle potřeby telefon)

## 6. FLOW — detailní popis funkcí

**URL (LIVE):** `https://www.ulovklienty.cz/flow/`  
**Účel:** Denní provozní prostředí majitele a personálu. Veřejný web a formulář rezervací pro zákazníky zůstávají odděleně; obsah webu se spravuje v ⚙ na webu provozovny.

### 6.1 Přístup a účty

| Téma | Popis |
|------|--------|
| Přihlášení | E-mail + heslo (e-mail globálně unikátní) |
| Session | Token FLOW, platnost cca 30 dní |
| Majitel | Stejné heslo jako webová administrace (⚙ → Heslo); heslo majitele se **ve FLOW nemění** |
| Pracovník | Vlastní FLOW účet; změna hesla v záložce **Účet** (min. 8 znaků, písmeno + číslo) |
| Aktivace majitele | Z webu ⚙ (**Přejít do FLOW**) nebo partner-admin |
| Aktivace pracovníka | Majitel ve FLOW → Správa → Personál (vytvoření, reset hesla, dočasné heslo + e-mail) |
| Blokace | Majitel může zablokovat / povolit **vstup do FLOW** (neprovádí deaktivaci zaměstnance na webu) |
| Overview | Příznak „vidí přehled všech rezervací“ (pro vybrané pracovníky) |
| Deaktivovaný účet | Nelze se přihlásit („Kontaktujte majitelku“) |

### 6.2 Co vidí a dělá **MAJITEL** ve FLOW

#### Provozní záložky (sdílený shell)

- **Můj den** — přehled rezervací / absence  
- **Kalendář** — měsíční pohled, rezervace dne, zadání rezervace  
- **Pracovní doba** — u majitele správa přes Správu personálu  
- **Overview** — týdenní přehled rezervací provozovny  
- **Dovolená** — zápis vlastního volna (schváleno), správa žádostí ve Správě  
- **Mail** — pokud je zapnutý IMAP ve web ⚙  
- **Účet** — informace o účtu (heslo majitele jen na webu)  
- **Správa** — pouze majitel (9 oblastí níže)  

**Alerty majitele:** platba ULOV po splatnosti, žádosti o volno, rizikové rezervace, nepřečtené maily.

#### Správa — 9 oblastí

| Oblast (UI) | Co majitel dělá |
|-------------|-----------------|
| **Rezervační pravidla** | Interval slotů, min. předstih, max. dopředu, storno zákazníkem (h), platnost odkazu potvrzení, auto-potvrzení rezervací personálu, URL recenzí |
| **E-mailové šablony** | Texty notifikací (předmět, tělo, offset, zapnutí) — transakční maily zákazníkům |
| **Personál a přístupy** | Přidat pracovníka; jméno, specializace, e-mail, číslo účtu pro QR; pracovní doba Po–Ne; vytvořit FLOW přístup; overview; blokace vstupu; reset hesla FLOW |
| **Přiřazení služeb** | Matice: který pracovník poskytuje které položky ceníku |
| **Žádosti o volno** | Zapsat absenci pracovníkovi; schválit / zamítnout žádosti; smazat absenci; po schválení řešit kolize (převést rezervaci / storno s omluvou) |
| **Platby partnera** | **Jen čtení:** splatnosti, částky, QR, historie; stažení PDF faktury ULOV |
| **NO-show / hříšníci** | Archiv NO-show; hledání; zablokovat / odblokovat e-mail pro online rezervace |
| **Audit log** | Historie změn v provozovně |
| **Statistiky** | Počty rezervací, dokončení, storna, NO-show; top služby a personál |

#### Akce u rezervací (majitel i oprávněný personál)

| Akce | Význam |
|------|--------|
| Proběhla | Označení dokončení |
| NO-show | Evidence nedorazení (+ volitelný e-mail zákazníkovi) |
| Platba QR | E-mail zákazníkovi s QR platbou |
| Požádat o zálohu | QR záloha |
| Záloha OK | Potvrzení přijetí zálohy |
| Storno | Storno ze strany provozovny + e-mail |
| Převod | Přesun rezervace na jiného pracovníka (zejm. při absencích) |
| Zadat rezervaci | Ruční rezervace (telefonicky / osobně / zaměstnancem) — služby, termín, jméno, e-mail nebo „nemá e-mail“, poznámky |

### 6.3 Co vidí a dělá **PRACOVNÍK (staff)** ve FLOW

| Záložka / funkce | Oprávnění |
|------------------|-----------|
| **Můj den** | Vlastní rezervace a absence; akce nad **vlastními** rezervacemi (dokončeno, NO-show, QR, záloha, storno) |
| **Kalendář** | Vlastní rozvrh a rezervace; zadání rezervace na sebe |
| **Pracovní doba** | **Jen náhled** — změnu dělá majitel ve Správě |
| **Overview** | Jen pokud má zapnutý `visible_overview` — přehled všech rezervací **bez** provozních tlačítek |
| **Dovolená** | Požádat o volno (stav čeká); smazat jen vlastní čekající žádost |
| **Mail** | Stejná sdílená schránka provozovny (pokud IMAP zapnutý) |
| **Účet** | Změna vlastního hesla |
| **Správa** | **Nedostupná** (403) |

**Pracovník nemůže:** měnit pravidla, šablony, personál, platby ULOV, hříšníky, audit, statistiky, přiřazení služeb; blokovat e-maily zákazníků; měnit cizí rezervace; vytvářet FLOW účty.

### 6.4 FLOW Mail (sdílená schránka)

- Zapnutí a IMAP/SMTP credentials: **web ⚙** (ne ve FLOW)  
- Ve FLOW: příchozí (on-demand z IMAP, neukládá se celý inbox do DB), odeslané (evidence odeslaných z FLOW), nový mail, odpověď  
- Účel: firemní komunikace týmu v provozním prostředí  

### 6.5 Interní banner

- Text + období nastaví majitel ve **web ⚙**  
- Po přihlášení do FLOW ho vidí tým (např. „Dnes nejde voda“)  

### 6.6 Co ve FLOW **není** (zůstává na webu ⚙ / jinde)

| Oblast | Kde |
|--------|-----|
| Název, popis, adresa, telefon, e-mail webu | Web ⚙ Základ |
| Hero, galerie, logo, favicon | Web ⚙ |
| Ceník (ceny, délky, aktivace položek) | Web ⚙ (FLOW jen přiřazuje služby personálu) |
| Novinky | Web ⚙ |
| Fotka / popis / „zobrazit na webu“ u personálu | Web ⚙ |
| Deaktivace zaměstnance jako entity | Web ⚙ |
| SMTP, URL rezervací, IMAP credentials | Web ⚙ E-mail |
| Heslo majitele | Web ⚙ Heslo |
| Verze GDPR zásad | Partner-admin / nastavení rezervací (ne editace ve FLOW Správě) |
| Veřejný formulář rezervace pro zákazníky | `rezervace.html` |
| Nahrávání faktur ULOV / potvrzení plateb partnera | Partner-admin (provozovatel platformy) |

## 7. Webová administrace (⚙) — shrnutí pro smlouvy

Majitel po přihlášení na webu provozovny spravuje:

- obsah a vzhled webu,  
- personál (prezentace na web),  
- ceník a novinky,  
- SMTP / IMAP / URL rezervací,  
- banner pro FLOW,  
- heslo majitele,  
- vstup do FLOW.

Zákazník provozovny **nemá** přístup do ⚙ ani do FLOW.

## 10. Co musí smlouva / VOP doplnit (mimo tento popis funkcí)

1. Identita smluvních stran, IČO, DIČ, kontakt.  
2. **Způsob a termín úhrady** vstupního poplatku a měsíčních plateb (účet, VS, splatnost, DPH).  
3. Aktivace služby vs. zaplacení; pozastavení při neplacení (systém umí indikovat platbu po splatnosti ve FLOW).  
4. Výpověď, výpovědní lhůta, data po skončení (web, doména, export).  
5. SLA podpory (reakční doby WhatsApp / e-mail / telefon).  
6. DPA odkaz — `dokumenty/`.  
7. Akční ceny do 31. 12. 2026 — „navždy“ = smluvní definice (indexace, změna ceníku).  
8. Doprava u Programu růstu (video) — hradí majitel.
